## What it is for

The **profile** holds your name, language and theme. This page uses the French spellings of the syntax, which
are accepted on an equal footing.

> [!ASTUCE]
> The theme follows the system's until you choose one.

## The screen

:::ecran{capture="settings-profile" titre="Settings · profile"}
1. **Profile**: name, language and theme.
2. **Save**: applies the changes.
:::

## Step by step

:::etapes
1. Open [[menu Settings]].
2. Change the **Profile**.
3. Click **Save**.
:::

## Settings reference

| Setting | Control | Values · default | Effect |
|---|---|---|---|
| Language | List | English · Français | Interface language |
| Theme | Switch | Light · Dark · System | Colours |

> [!ERREUR] Save refused
> An empty name is refused by the API.

## Required permissions

> [!DROITS]
> Save: [[droit settings:write]]; status [[statut open]]; shortcut [[touche Ctrl+S]].
